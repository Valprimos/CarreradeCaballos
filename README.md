# Carrera de caballos con baraja española

Juego de cartas para navegador. Sin dependencias: solo `index.html` y la carpeta `cartas/`.

Para publicarlo: sube todo a un repositorio y activa GitHub Pages (Settings > Pages > rama `main`, carpeta `/ (root)`).

## Créditos

Ilustraciones de las cartas de [Basquetteur](https://commons.wikimedia.org/wiki/User:Basquetteur) (Wikimedia Commons), en la versión SVG de [spanish-playing-cards-svg](https://github.com/gjenkins20/spanish-playing-cards-svg), bajo licencia [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

Las imágenes se han adaptado para utilizar únicamente una baraja de 40 cartas (sin ochos ni nueves). Las ilustraciones no se han modificado.
